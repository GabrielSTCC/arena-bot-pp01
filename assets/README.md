# Assets gráficos (Arena Bot)

Sprites autorais em PNG 48×48 (RGBA), usados pelo [`ui/renderer.py`](../ui/renderer.py).
Se algum arquivo faltar, o jogo volta ao desenho geométrico.

| Arquivo | Uso |
|---------|-----|
| `robo_alfa.png` | Robô Alfa (accent azul) |
| `robo_beta.png` | Robô Beta (accent coral) |
| `tile_wall.png` | Parede intransitável |
| `tile_blocked.png` | Armadilha (custo extra) |
| `diamante.png` | Minério diamante (100) |
| `rubi.png` | Minério rubi (80) |
| `ouro.png` | Minério ouro (50) |
| `prata.png` | Minério prata (30) |
| `bronze.png` | Minério bronze (10) |

Não reutilizar PNGs do projeto de referência do professor (`PP01`).
